# 此次发布的核验记录

日期：2026-10-05（北京时间）。这些记录针对脱敏发布包，不是“所有实机功能正常”的证明。

## 发布包检查

- 中文屏幕 13 项离线测试通过：画面尺寸/按钮边界、锁屏禁止网络修改、PIN 校验/冷却、原厂冷却、模态窗口阻止背景操作、Wi-Fi 密码 stdin 传输、网口参数保存、连接状态判定等。
- 无线 Lua 解析/语法测试通过：UTF-8、安全能力、BSSID 去重、LTE/SA/NSA、邻区、无效信号与隐私字段。
- AGH 前五测试通过：0/5/100 项、顺序/总量/其他字段保持、JSON 转义、空数组、幂等。
- OpenClash 网页测试通过：控制面板端口/IPv6 主机名、无密钥 URL、服务停止状态、额度/空值/旧数据、刷新保留草稿。
- 无线网页测试通过：示例渲染、纯文本 SSID、防注入、筛选、失败缓存与空结果。
- Python 源码编译、Node 语法和公开文件审查通过。Ruby 规则测试作为可复现测试保留，此次本地发布没有 Ruby 运行时，因此未重新运行。
- 35 张文档 PNG 全部由示例数据生成，公开图库没有从实机下载的私人截图。部分画面已做视觉检查；字库/壁纸源文件没有提交。
- Markdown 相对文件链接和图片路径检查通过；凭据形态检查、文件类型和 EXIF 检查通过。模式扫描不是完整安全审计。

## 历史实机开发检查（不同于此次发布）

开发设备曾检查真实锁屏 framebuffer、原密码校验、手动切回/重新启用和三次异常退出自动恢复原厂；代理 IPv4/IPv6、AGH、订阅 metadata、无线结果状态读取曾通过。原厂配置字节比较未变化。

**但是设备使用者随后反馈多个功能不正常和 UI 不满意。** 实体触摸、完整屏幕交互、中继实际替换、网口实际切换没有完整回归，本项目仍为实验状态。后续需要按页面收集复现并修复，不能用上述历史检查或文档图覆盖这项反馈。

## 发布版与设备版本的差异

- 私人域名替换为保留域名示例，网页改为通用自定义规则提示。
- AGH 用户名改为环境变量，去掉固定身份。
- 固定设备 ULA 移除，改读本机 UCI。通用防火墙版本未回写开发设备，仍需目标设备验收。
- 本地依赖导入不再引用个人 TEMP 目录。
- sysupgrade 改为追加合并，只保留源码项；没有发布原始设备配置。
- 新增文档、截图生成、公共文件检查工具。这些整理没有更改路由器上实际运行的配置。
