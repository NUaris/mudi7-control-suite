# 安全与公开发布说明

## 未发布的数据

本仓库不包含 SSH/AGH 密码、原厂屏幕 PIN、订阅 URL/订阅内容、控制器 secret、Wi-Fi 密钥、Basic 授权文件、AGH 原始配置、访问历史、原始 UCI 配置、设备备份或实机私人截图。

固定个人直连域名改成保留域名 `example.com`；固定 AGH 用户名改成环境变量 `ADGUARD_TASK_USERNAME`（默认示例 admin）。设备私有 IPv6 前缀移除，发布版防火墙钩子读取本机 ULA；测试 IPv6 改用文档前缀 `2001:db8::/32`。

发布版辅助工具从正常 Python 包导入依赖，不依赖个人电脑 TEMP 路径；sysupgrade 项采用追加合并，未发布某台设备的完整保留配置。

## 运行时凭据

- SSH 密码通过本地环境变量给助手，不写入仓库。按需输入，用后清除；更推荐管理好 SSH 密钥和主机指纹。
- AGH 用户密码通过 SSH stdin 传输并生成 bcrypt 哈希。后台随机账号的授权文件只存设备 root-only 路径，不返回给网页。
- Mihomo 控制器密钥只在本机读取，通过请求头传递，不放进控制面板入口 URL。
- Wi-Fi 连接密码通过 Lua 桥接的 stdin 输入，不放在命令参数里；复用原厂保存配置。输入页退出/重新锁屏清理界面缓存。
- 原厂屏幕 PIN 仅按需读取到内存，没有第二份持久明文副本；仍受 root 访问权限约束。

原厂页面统计入口继续校验厂商 Admin-Token；后台凭据只允许用于两个固定统计端点，不注入通用 `/control/`。屏幕后台仅访问 loopback 固定端点，不新增 HTTP 监听。

## 发布检查清单

1. 只添加明确列出的源码/文档/示例 PNG，不直接 `git add` 整个开发目录或路由器 `/etc`。
2. 搜索硬编码密码、订阅 URL、认证字符串、账户/SSID/节点/个人域名、设备 IPv6、私有路径。
3. 检查图片元数据与生成方式；原图只有代码渲染示例，不能靠肉眼模糊处理替代数据脱敏。
4. 检查 `git diff --cached` 和所有即将推送文件；不要提交备份、字体、二进制、授权文件、缓存。
5. 使用 `python tools/audit-public.py` 检查已跟踪文件类别和常见凭据形态；它是辅助检查，不是完整安全审计。

不要在 issue 或日志中贴完整 UCI/YAML、HTTP Cookie/Authorization、订阅链接、Wi-Fi 密钥、SIM 身份或浏览历史。如误泄露，立即撤销/更换凭据；仅删文件不能清除既有 Git 历史。

## 权限和边界

本套件在设备上以 root 运行，能够修改网络和服务。四位屏幕密码不能代替管理员认证。只在信任的内网使用管理接口，不把 RPC、9090 控制器或 AGH 管理端口暴露到公网。

依赖原厂内部接口，不代表经官方安全审计。失败提示、输入白名单与回退只是风险缓解，不能保证任意固件或异常下网络连续性。
